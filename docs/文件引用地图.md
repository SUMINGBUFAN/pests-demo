## 六、结论

1. 报告与网页完全依赖「`outputs\<显式 run 名>` + `code\report_src\`」，本次只把 `report_src` 从根挪到 `code\report_src` 并已同步 `build_report.py`、`render_snippet.py`。
2. `runs\`、`figures\` 只被旧流水线脚本引用，可随旧流水线一起搬走，但 6 个脚本的 `ROOT`/`RUNS_DIR`/`FIGURES` 常量必须同步改写。
3. `outputs\` 下所有 run 目录、`.pth`、`.csv`、`.md`、`.json` 一律不动，报告数字的读取路径零变化。
