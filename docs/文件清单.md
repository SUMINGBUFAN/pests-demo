## 二、刻意未动及原因

| 目标 | 原因 |
|---|---|
| `outputs\` 下全部 run 目录名（`E1_simple_baseline`、`E2_resnet18_pretrained`、`E3_deep`、`E4_residual`、`E6_se_residual`、`P2_se_residual_cosine`、`P3_resnet18_full`、`P4_se_res_balanced`、`P5_*`、`P6_small_none_cos40`、`E1s_small_none`、`P1c_*`、`P1d_small_augcos`、`smoke_test`、`analysis`、`holdout`、`_current_run` 等） | 铁律 1：报告、消融表、速查页靠路径读数字，改名即全篇作废 |
| `outputs\<run>\*.pth` | 训练产物，`eval_holdout.py` / `web_app.py` / `analysis\val_errors_gradcam.py` 直接加载 |
| `outputs\*.csv` / `*.json` / `*.md` / `*.png`（`ablation_table.md`、`dataset_stats.json`、`compare_all.png`、`test_demo_result.jpg`、`_wtest.txt` 等） | 报告数字与网页的数据源，非缓存，不删不搬 |
| `data\Pests_dataset\` | 原始只读数据，引用遍及全链路 |
| `outputs\log_*.txt` | 历史训练日志，非缓存 |
| `code\report_src\snippets\*.png` | `build_report.py` 按文件名逐个插入，改名即断 |
| `code\test.py`、`visualize.py`、`summarize.py`、`print_struct.py`、`run_extra.py`、`prepare_data.py`、`render_snippet.py` | 属当前工具脚本（`visualize` 被 `train.py` import），不在指定迁移清单，保持原位 |
| `code\report_src\` 内旧 PDF 副本与 `page-01..10.png` | 无引用但非缓存，不删；随 `report_src` 整体移动 |
| `交付物\*.docx` / `.pdf` | 重建后的正式产物（13 页） |
